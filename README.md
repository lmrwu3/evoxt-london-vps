### 去程路由（从国内出去）

- **电信**：北京 → 法兰克福 → Cogent（AS174）→ 伦敦，走的是德国中转的标准国际线路
- **联通**：北京 → 法兰克福 → GTT/Zare（AS25369）→ 伦敦，联通在欧洲有自己的 PoP，延迟相对好看
- **移动**：北京/沈阳 → 绕美国 → Cogent → 伦敦，是的，移动绕美了，这是伦敦节点最大的硬伤

### 回程路由（从伦敦回来）

回程路由相对统一，主要走 Arelion（就是以前的 Telia）：

- **电信回程**：Arelion → China Telecom 163（AS4134）
- **联通回程**：Arelion → China Unicom 4837，三个方向分别经巴黎、法兰克福出海回国
- **移动回程**：Arelion → CMI 直连回国（上海方向走伦敦 peer，广州方向走伦敦节点，北京方向绕美国圣何塞）

**结论很直接**：联通用户首选，电信用户可接受，移动用户建议挂一个香港或日本的 relay 节点中转，否则绕美体验会打折扣。
